# State and error taxonomy

Generated by `pnpm api:openapi` from `packages/contracts/src/openapi-states.ts`. Do not edit by hand.

Exactly 12 states. `ErrorResponse.state` (v1.7.0, additive and optional) carries one for refusals; data envelopes carry `DataStateEnvelope.state`. `errorCode`, `reasonCode` and the HTTP status are unchanged.

| State | Kind | Retryable | Meaning | Frontend |
|---|---|---|---|---|
| `loading` | data | no | Work is in progress and no usable result exists yet. | Show a skeleton; follow the SSE stream or poll the run. |
| `partial` | data | no | Some panels, sources or tasks finished; others are still running or failed. | Render what exists, label the rest; never present as complete. |
| `complete` | data | no | Everything requested was produced from current data. | Render normally. |
| `stale` | data | yes | A result is shown but its source is behind (watermark older than the freshness target, or served from the last finalized snapshot). | Render with the freshness warning (`asOf`, `staleSeconds`); do not publish as current. |
| `truncated` | data | no | The max-rows rule cut the result; `truncation` says how and by how much. | Label as truncated or downsampled; offer a narrower query. |
| `source_unavailable` | refusal | yes | The source, semantic layer or breaker is down and there is no snapshot to serve. | Show the unavailable state with `nextAction`; retry with backoff. |
| `permission_denied` | refusal | no | Not signed in, not a member, role too low, origin not allowed or classification denies access. | Re-authenticate or hide the action; do not retry. |
| `rate_limited` | refusal | yes | Too many requests, queue full or too many streams; `Retry-After` and `retryAfterSeconds` give the wait. | Back off for Retry-After seconds; keep the same x-client-id. |
| `insufficient_data` | refusal | no | The data cannot support the answer (CANNOT_COMPUTE, coverage gap, too few observations, vintage missing). | Say what is missing; never fill with zero. |
| `metric_uncertified` | refusal | no | The metric is a draft, validated-only or deprecated and may not be used for a certified claim. | Label exploratory; block publication. |
| `method_unvalidated` | refusal | no | The analysis method has not passed validation (METHOD_NOT_VALIDATED, inference guard). | Label the finding as unvalidated; require acknowledgement to publish. |
| `budget_exhausted` | refusal | no | A spend limit stopped paid work: the global USD 5 model ceiling, a workspace cap, a per-resource limit or an unknown price. | Show the budget card; historical reads still work; the owner must raise a limit. |
